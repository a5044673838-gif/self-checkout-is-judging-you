One funny line in the voice of a smug self-checkout machine, written for
make.fun's "The Self-Checkout Is Judging You" bounty.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

The program writes a single line (at most 200 characters) to
`/output/entry.txt`.
